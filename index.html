Tariximiz

Forumdan açıq icmaya

CodeStack.az kiçik bir sual-cavab forumu kimi başladı və illər ərzində Azərbaycan developer icmasının bir hissəsinə çevrildi.

1
Başlanğıc

Forum kimi doğuldu

Proqramçılar üçün texniki sual-cavab platforması — kod xətalarından tutmuş yerli ödəniş sistemlərinin (Millikart, AzəriCard) inteqrasiyasına qədər.

2
Dönüş nöqtəsi

Sayt bağlandı

codestack.az domeni fəaliyyətini dayandırdı, lakin icmanın topladığı bilik və əlaqələr itmədi.

3
Bu gün

GitHub üzərində, sərbəst

İndi mərkəzsiz, açıq mənbə icması kimi davam edirik — hər kəsin qoşula, töhfə verə və istifadə edə biləcəyi formada.

Nə edirik

Kod yazmaq tək başına deyil, birlikdə daha yaxşıdır

CodeStack-in mərkəzində insanlar var — biri-birinə kömək edən, bilik bölüşən və birgə layihələr quran proqramçılar.

Açıq mənbə layihələr

Birgə qurduğumuz alətlər və kitabxanalar hər kəs üçün açıqdır — GitHub üzərindən izlə, fork et, töhfə ver.

Bilik bölüşümü

Qarşılaşdığın texniki problemi paylaş, icmadan həll yolu tap — Azərbaycan reallığına uyğun cavablarla.

Mentorluq

Yeni başlayan proqramçılar təcrübəli üzvlərdən yol xəritəsi, məsləhət və istiqamət alır.

Yerli təcrübə

Millikart, AzəriCard kimi yerli inteqrasiyalardan tutmuş real bazarın texniki problemlərinə qədər — burada həll var.

Gördüyümüz işlər
